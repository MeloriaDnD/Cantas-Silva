- icon-180.png / icon-512.png

Für GitHub Pages:
1. Neues Repository anlegen.
2. Diese Dateien in die oberste Ebene hochladen.
3. Repository > Settings > Pages.
4. Deploy from a branch / main / root auswählen.
5. Veröffentlichte URL in Safari auf dem iPad öffnen.
6. Teilen > Zum Home-Bildschirm > Als Web-App öffnen aktivieren.

Nach dem ersten erfolgreichen Öffnen wird die Seite über den Service Worker
für Offline-Nutzung gecacht. Der Tracker speichert seinen Zustand lokal im Browser.
